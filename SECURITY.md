# Security Policy

## Reporting a Vulnerability

If you discover a vulnerability affecting this repository or keroway's published tools, please
report it through GitHub's **Private vulnerability reporting** rather than a public issue.

- Repository **Security** tab → **Report a vulnerability**
- <https://github.com/keroway/homebrew-tap/security/advisories/new>

Reports are reviewed privately; a Security Advisory will be published after a fix if warranted.
Reproduction steps and the scope of impact are appreciated.

日本語

## 脆弱性の報告

このリポジトリおよび keroway 製ツールに関する脆弱性を発見した場合は、公開 Issue ではなく
GitHub の **Private vulnerability reporting** からご報告ください。

- リポジトリの **Security** タブ → **Report a vulnerability**
- <https://github.com/keroway/homebrew-tap/security/advisories/new>

報告内容は非公開で確認し、修正後に必要に応じて Security Advisory を公開します。
再現手順・影響範囲を添えていただけると助かります。
